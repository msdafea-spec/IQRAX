# IQRAX
THE LLM TRUTH TELLER
What it is
A PDF with a cover page that holds a prompt. The pages after the cover are the published IQRAX paper.

How to use it
1. Open the chat that holds the work you want checked.
2. In that same chat, attach The_LLM_Truth_Teller.pdf. 
3. Send the prompt in PROMPT.txt, or type: "Follow the prompt on the cover page of the attached file.
